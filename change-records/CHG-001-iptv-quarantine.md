## 1. Rollback / Recovery

| Level | Recovery point |
|---|---|
| Current | Post-change configuration archive (stored offline) |
| Level 1 | Previous router, retained unmodified with its original configuration |

## 2. Device Setup

- Previous router disconnected and retained unmodified for rollback
- New router connected to the ISP modem via the dedicated WAN port
- Unique admin password set (stored in a password manager)
- Default SSID renamed — the default name disclosed the device model
- Default Wi-Fi passphrase replaced — the label credential is no longer valid
- 160 MHz / DFS channels deferred until configuration was complete (availability)

## 3. Firmware — SI-2 Flaw Remediation

- Upgraded from the factory firmware to the latest **stable (release)** vendor firmware, settings kept
- Status after upgrade: *"Firmware is up-to-date"*; automatic update check left **on**
- Unofficial community firmware **rejected** (unsigned, preview status)
- Any future firmware upgrade is a separate change, because it may affect the custom VLAN configuration

## 4. Port Mapping

- The IPTV box is the only wired device; all other devices use Wi-Fi
- Physical LAN port labels do **not** match the switch port names in the configuration interface, so the mapping was confirmed by testing
- The IPTV box negotiates 100 Mbps only — consistent with legacy hardware on an end-of-life device
- **Temporary exposure:** the IPTV box sat on the default VLAN for about 2 minutes to identify its port, then was disconnected until isolation was in place

## 5. Switch VLAN — SC-7 Boundary Protection

| VLAN | CPU port | IPTV port | Other LAN ports |
|---|---|---|---|
| 1 (default) | tagged | **off** | untagged |
| **30 — IPTV-Quarantine** | tagged | **untagged** | off |

The internal switch was not modified.

## 6. Interface & Firewall — AC-4, SC-7(5)

**Interface:** `IPTV` on VLAN 30 — `x.x.30.x/24`, static address, DHCP enabled, no upstream gateway configured.

**Global firewall defaults (verified, unchanged):** Input REJECT / Output ACCEPT / Forward REJECT

**Zone `IPTV`:**

| Setting | Value |
|---|---|
| Input | REJECT |
| Output | ACCEPT |
| Forward | REJECT |
| Masquerading | Off (NAT is handled by the WAN zone) |
| Forward **to** | `wan` only |
| Forward **from** | none |

**Traffic rules (IPTV → router only):**

| Rule | Protocol | Port |
|---|---|---|
| Allow-IPTV-DHCP | UDP | 67 |
| Allow-IPTV-DNS | TCP + UDP | 53 *(protocol verified 2026-11-22)* |

**Casting/control exception:** none. Deny by default; an exception would be added only if a demonstrated need arises, and documented.

**Additional hardening:** Wi-Fi disabled on the IPTV box and saved networks removed. This closes the wireless path that could bypass VLAN 30.

## 7. Verification & Testing

| Test | Result | Evidence |
|---|---|---|
| **4A** Reboot persistence | ✅ PASS — VLAN, interface, zone and rules present after restart (reboot time derived from uptime) | 10, 10b |
| **4B** IPTV reconnected on VLAN 30 | ✅ PASS — streaming works; lease in `x.x.30.x/24` | 11 |
| **4C-1** Positive control (Kali → router) | ✅ PASS — 4/4, 0% loss | 12 |
| **4C-2** Ping IPTV from trusted | ✅ PASS — "Destination Port Unreachable" from router, 100% loss | 13 |
| **4C-3** Nmap 139/445 (SambaCry) | ✅ PASS — `closed`, `reset ttl 64` | 14 |
| **4C-4** Nmap top 100 ports | ✅ PASS — 100/100 closed (reset), 0 open | 15 |
| **4D** Inside-out (IPTV → trusted / router) | ⚪ **Not performed** (owner decision) | — |

**Reading the TTL:** a reset arriving at TTL 64 was generated by the router, one hop away. A reply from the device itself would have arrived at TTL 63 after being routed. The scans never reached the vulnerable service.

**Scope of assurance:**
- **Inbound** (trusted → IPTV), the path the RCE requires: **verified by testing**
- **Outbound** (IPTV → trusted / router admin): **enforced by firewall policy, verified by configuration review only** (evidence 07–10)

**Corrections recorded:**
- 4B lease check was first reported as "not found." On review, the lease was present (the device reports no hostname). This was a misread, not a control failure.
